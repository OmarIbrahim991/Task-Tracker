# Feature 1: Project Documentation (AGENTS.md, CLAUDE.md, README.md)

## Overview
Create standard project documentation files in the repository root: `AGENTS.md` (AI agent workspace guide), `CLAUDE.md` (quick start & development commands), and `README.md` (comprehensive user-facing project documentation).

## User Stories
- As a developer or AI assistant, I want an `AGENTS.md` file in the root directory so that AI agents understand codebase conventions, architecture, and constraints.
- As a developer using Claude or AGY CLI, I want a `CLAUDE.md` file with quick terminal commands and style guidelines.
- As an open-source contributor or user, I want a well-structured `README.md` explaining project features, stack, setup, and usage.

## Implementation Plan

### Files to Create
1. **`AGENTS.md` (Root)**:
   - System overview: Decoupled Django REST Framework backend + React Vite frontend.
   - Key constraints: Native HTML5 drag & drop without 3rd party dnd libraries, Light/Dark mode state management, no auth (Admin user), pnpm package manager.
   - Code formatting rules: Python PEP 8 (4 spaces), JS 2 spaces with semicolons.
   - File header requirement: `# Generated by <MODEL_NAME> on <YYYY-MM-DD>` for Python / `// Generated by...` for JS/CSS.

2. **`CLAUDE.md` (Root)**:
   - Build, run, and test commands for `backend/` and `client/`.
   - Summary of backend endpoints (`/api/tasks/`).
   - Summary of frontend component structure and theme provider.

3. **`README.md` (Root)**:
   - Project title, badges, and feature highlights.
   - Tech stack summary (Django, DRF, SQLite, React, Vite, pnpm, Lucide React).
   - Installation & Quick Start guide for both backend and client.
   - PWA & Theme switching documentation.
   - API Reference table.

### Step-by-Step Implementation
1. Create `AGENTS.md` in workspace root.
2. Create `CLAUDE.md` in workspace root.
3. Create `README.md` in workspace root.

## Acceptance Criteria
- [ ] `AGENTS.md` exists in root detailing AI workspace guidelines and architecture rules.
- [ ] `CLAUDE.md` exists in root listing build/dev commands and conventions.
- [ ] `README.md` exists in root with setup instructions for Django backend and React client.

## Dependencies
- **Internal**: None (independent feature).
- **External**: Markdown documentation standard.
